# ВАЖНО: Python 3.14 на Windows без компилятора C++/Rust.
# Основные пакеты уже берутся из готовых wheel (включая torch, chromadb, openai, jiter).
# 1) llama-cpp-python берётся из готового CPU-wheel без AVX (см. строку выше):
#    обычные сборки используют AVX2/AVX-512 и падают с 0xc000001d на CPU без этих
#    инструкций; сборка из исходников требует CMake (nmake not found).
# 2) ragas нельзя ставить из этого файла: его зависимость scikit-network не имеет
#    wheel для cp314 и требует компилятор C++. Установите ragas отдельно:
#      pip install ragas --no-deps
#      pip install appdirs diskcache instructor langchain-openai==0.3.35 datasets tiktoken pydantic
#    langchain/langchain-core/langchain-community уже поставлены из этого файла.
#    Для ragas 0.4.3 обязателен langchain-community<0.4 (иначе import ragas падает:
#    ModuleNotFoundError: langchain_community.chat_models.vertexai), а langchain-openai
#    должен быть версии 0.3.x: пин 0.2.14 тянет openai<2 и конфликтует с instructor.
# 3) pystemmer (зависимость llama-index-retrievers-bm25, пин pystemmer<3) на Python 3.14
#    не имеет готового wheel и собирается из исходников — на чистом ПК нужен C-компилятор
#    (MSVC Build Tools).
