# Отчёт: багфиксы и новые фичи интерфейса

- Дата: 2026-10-27
- Задача: починить ошибки и добавить статистику, управление материалами и автозапуск.

## Багфиксы

1. `.streamlit/config.toml` — `fileWatcherType = "none"` (Streamlit больше не сканирует тяжёлые библиотеки, ошибка torchvision).
2. `ui/app.py` — перед вызовом облачной/кастомной модели проверка API-ключа: если пустой — `st.error("Ошибка: Введите API-ключ в настройках.")` и остановка.

## Автоматический список моделей

- Локальные: `glob("modules/*.gguf")` → имена в `st.selectbox`.
- Облачные: GET `https://openrouter.ai/api/v1/models` (через `requests`, с кэшем `@st.cache_data`) → список ID; чекбокс «Только бесплатные» фильтрует по `:free`.

## Настройки и статистика

- `st.slider` «Макс. токенов» (128–2048), значение передаётся в `get_llm(..., max_tokens=...)`.
- Вкладка «📊 Статистика»: замер времени (`time.time()`), подсчёт токенов через `tiktoken`, вывод `st.metric` (время, токены, модель, размер контекста).

## Управление материалами

- Вкладка «📚 Материалы»: кнопка «Переиндексировать корпус» (`subprocess.run(["python","src/ingest.py"])`), загрузка PDF через `st.file_uploader` в `data/`, список файлов с размером.

## Автозапуск

- `run_all.py` — через `subprocess.Popen` одновременно запускает `uvicorn api.main:app --port 8000` и `streamlit run ui/app.py`.

## Запуск

```powershell
.venv\Scripts\python.exe run_all.py
```
