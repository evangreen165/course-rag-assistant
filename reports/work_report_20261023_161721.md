# Отчёт о проделанной работе

- Время: 2026-10-23 16:17:21
- Задача: исправление пагинации в `src/rag_pipeline.py`

## Проблема

`rag_pipeline.py` падал с `chromadb.errors.InternalError: ... too many SQL variables`. Функция `get_all_nodes` выгружала все 37 984 документа одним вызовом `collection.get()`, что превышало лимит SQLite (внутри ChromaDB) на число переменных в одном запросе.

## Исправление

Функция `get_all_nodes` переписана на постраничную загрузку:
- общее число документов получается через `collection.count()` (37 984);
- документы загружаются порциями по 5000 через `collection.get(include=["documents", "metadatas"], limit=5000, offset=offset)`;
- для каждой записи создаётся `TextNode(text=..., metadata=...)` и добавляется в общий список.

## Проверка

- Синтаксис: OK (`py_compile`).
- Функциональный тест на полной базе: загрузка прошла за 8 батчей (5000 → 37 984) без ошибки SQL, итого `TOTAL NODES: 37984`. Метаданные (например, `file_name`) читаются корректно.
