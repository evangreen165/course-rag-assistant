# Отчёт: первый прогон RAGAS

- Дата: 2026-10-23
- Задача: базовая оценка качества RAG-пайплайна метриками RAGAS.

## Результаты первого прогона

- Оценка завершилась (заняла ~2 часа, судья 7B на CPU).
- **Поиск работает отлично**: Context Recall = 1.0 — нужный контекст стабильно находится гибридным поиском (BM25 + Vector).

## Выявленные проблемы

1. **Генератор (1.5B) зацикливается** и переходит на английский (артефакты вида `The original answer...`).
2. **Судья (7B) падает с `RagasOutputParserException`** — ему не хватало токенов, чтобы корректно закрыть JSON, ответ обрывался на полуслове.

## Исправления

- Генератор: строгие стоп-токены (`The original answer`, `The refined answer`, `Original Answer:` и др.), `repeat_penalty` повышен до 1.3, в системный промпт добавлено жёсткое требование отвечать только на русском и без комментариев.
- Судья: `max_tokens` увеличен с 256 до 1024 (чтобы хватало места закрыть JSON), `n_ctx=8192`, `RunConfig(max_workers=1, timeout=1800)`.
