# Отчёт о проделанной работе

- Время: 2026-10-22 15:46:24
- Задача: исправление критической ошибки извлечения текста из PDF в `src/ingest.py`

## Проблема

Скрипт `ingest.py` читал PDF штатным парсером `pypdf` (через `SimpleDirectoryReader` по умолчанию), который извлекал бинарный мусор: первый чанк начинался с `%PDF-1.4`. В результате в ChromaDB (коллекция `course_rag`) попало **17 295 бесполезных чанков**, обработка заняла ~4 часа впустую.

## Выполненная работа

1. Установлены пакеты:
   - `pymupdf 2.0` — качественный парсер PDF (хорошо работает с русскими и сложными PDF).
   - `llama-index-readers-file 0.7.0` — обязателен, т.к. модуля `llama_index.readers.file` нет в базовом `llama-index`; без него не импортируется `PyMuPDFReader`.
   - Побочный эффект: `llama-index-readers-file` понизил `pandas` с 3.0.6 до 2.3.3 (у пакета пин `pandas<3`). На работу не повлияло.

2. Исправлен `src/ingest.py`:
   - добавлен импорт `from llama_index.readers.file import PyMuPDFReader`;
   - в `SimpleDirectoryReader` передан `file_extractor={".pdf": PyMuPDFReader()}`;
   - добавлен фильтр мусора `is_garbage()`: отбрасывает текст с `%PDF`, нулевыми байтами `\x00` и долей печатных символов меньше 80%;
   - добавлен вывод статистики: сколько файлов прочитано успешно, сколько отброшено;
   - первый чанк печатается как первые 200 символов.

3. Очистка и перезапуск:
   - папка `chroma_db/` удалена;
   - выполнен прогон `ingest.py --folder git` для проверки.
