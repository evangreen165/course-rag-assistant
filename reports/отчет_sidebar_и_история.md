# Отчёт: фиксация sidebar и мгновенное сохранение чатов

- Дата: 2026-10-27
- Задача: жёстко зафиксировать UI-sidebar и сделать мгновенное сохранение чатов.

## Sidebar и провайдер (`ui/app.py`)

- Выбор провайдера переведён с `st.selectbox` на `st.radio` (Локальная/Облачная/Кастомная через `format_func`).
- Для «Облачной»: сначала `st.checkbox("Только бесплатные модели", value=True)`, затем `fetch_openrouter_models()` (с `@st.cache_data(ttl=600)`), фильтр `:free`, `st.selectbox` моделей; если список пуст — `st.text_input("Введите ID модели вручную", ...)`.
- Для «Кастомной» чекбокс «Только бесплатные» не показывается.

## Мгновенное сохранение чатов (`ui/app.py`)

- Добавлен `st.session_state.pending_question`.
- При отправке сообщения: создаётся чат с заголовком из первых 20 символов вопроса (если его ещё нет), сообщение пользователя сразу добавляется в `chat_history`, сохраняется в `history.json` и вызывается `st.rerun()` — чат сразу появляется в sidebar.
- После rerun `pending_question` обрабатывается в `_answer()`: запрос к `query_engine`, добавление ответа ассистента в историю и сохранение.
- Список чатов в sidebar перебирает `chat_history.items()` и по клику переключает `current_chat_id`.

## Запуск

```powershell
.venv\Scripts\python.exe -m streamlit run ui\app.py
```
