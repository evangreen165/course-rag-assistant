# Отчёт: исправление 401, списка моделей и кастомных провайдеров

- Дата: 2026-10-27
- Задача: исправить ошибку 401 и улучшить настройки провайдеров.

## Изменения

1. **Ошибка 401 (API-ключ)**:
   - `src/llm_factory.py`: для `cloud`/`custom` выбрасывается `ValueError("API-ключ не может быть пустым")`, если ключ пустой.
   - Добавлены обязательные заголовки OpenRouter в `ChatOpenAI`: `default_headers={"HTTP-Referer": "http://localhost:8501", "X-Title": "RAG Assistant"}`.

2. **Список моделей и чекбокс**:
   - Чекбокс «Только бесплатные модели» теперь идёт первым и по умолчанию включён (`value=True`).
   - Запрос к `openrouter.ai/api/v1/models` передаёт `Authorization: Bearer <ключ>`, если ключ введён.
   - При пустом списке моделей выводится `st.warning(...)`.

3. **Кастомные провайдеры**:
   - Добавлено поле «Название провайдера (например, MyLocalAPI)».
   - Структура настроек дополнена словарём `custom_providers`: `{Название: {base_url, api_key, model_name}}`.
   - Выпадающий список сохранённых провайдеров для переключения.
   - При сохранении новый провайдер добавляется в `custom_providers`.

## Запуск

